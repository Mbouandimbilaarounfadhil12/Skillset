   └─ GoogleCalendarService.java
      Path: src/main/java/com/skillset/infrastructure/integration/GoogleCalendarService.java
      - Handles all Google Calendar API interactions via REST
      - 5 main methods:
        a) getAuthorizationUrl(UUID userId) - OAuth2 URL generation
        b) handleOAuthCallback(String code, UUID userId) - Token exchange
        c) createCalendarEvent(...) - Event creation
        d) updateCalendarEvent(...) - Event updates
        e) deleteCalendarEvent(...) - Event deletion
      - Graceful error handling with logging
      - Uses RestTemplate for HTTP calls
      - Uses ObjectMapper for JSON serialization

        c) GET /status - Checks connection status (@PreAuthorize EMPLOYER)

DATABASE MIGRATION (SQL - NOT APPLIED)

Run these SQL commands to set up database:

CREATE TABLE google_calendar_tokens (
    id UUID PRIMARY KEY DEFAULT gen_random_uuid(),
    user_id UUID NOT NULL,
    access_token TEXT,
    refresh_token TEXT,
    expires_at TIMESTAMP,
    calendar_id VARCHAR(255),
    created_at TIMESTAMP NOT NULL DEFAULT CURRENT_TIMESTAMP,
    updated_at TIMESTAMP DEFAULT CURRENT_TIMESTAMP
);

CREATE INDEX idx_google_tokens_user_id ON google_calendar_tokens(user_id);

ALTER TABLE interviews ADD COLUMN google_event_id VARCHAR(255);
ALTER TABLE interviews ADD COLUMN calendar_sync_status VARCHAR(20);

API ENDPOINTS
================================================================================

GET /api/integrations/google/auth
  - Authorization: EMPLOYER role required
  - Returns: {authUrl: "https://accounts.google.com/..."}

GET /api/integrations/google/callback?code=...&state=...
  - Authorization: None (OAuth callback)
  - Returns: {success: true, message: "..."}

GET /api/integrations/google/status
  - Authorization: EMPLOYER role required
  - Returns: {connected: true, connectedAt: "...", expiresAt: "..."}

DELETE /api/integrations/google/
  - Authorization: EMPLOYER role required
  - Returns: 204 No Content
